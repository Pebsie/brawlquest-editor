BrawlQuest Editor

BrawlQuest Content Editor

Open (or drop here) a bq-content.db. Everything happens in this tab: nothing is uploaded.

  • Quests and their steps, NPCs and dialogue trees, items and loot tables
  • Mobs and their boss pattern primitives (zones, soaks, scripted moving zones, projectiles) with a live preview
  • Status effects (buffs and debuffs such as Webbed Up) that projectiles apply
  • World map with sprites: drag NPCs and mobs, place spawns, paint tiles
  • Save .db downloads the edited database for the game; Export SQL gives the same changes as a migration

Quests need the questline migration (quest_def table). Never open bq-users.db here.

The previous editor is still at legacy/.
